# Locandine dei teatri di Gravellona Lomellina

Archivio delle locandine della **Compagnia Teatrale Gravellonese** e del
**Teatro/Cinema San Faustino** (1984–2017): 19 foto di bacheche + un ritaglio
di giornale.

- Gallery: `index.html`
- Indice ragionato degli spettacoli: `INDICE.md`
- Originali: `locandine/` (19 file JPG)
- Pagina HTML salvata: `2017-02-12_miti-damore-e-di-note_pagina.html`

Canale YouTube della compagnia:
<https://www.youtube.com/@compagniateatralegravellon7214> (id `UCNJmxBgPY0i-4s9jQsNh2Ag`).

## Diritti

Le locandine restano dei rispettivi autori e organizzatori (Compagnia
Teatrale Gravellonese, Teatro San Faustino, Teatro Mutuo Soccorso). Raccolte
a scopo di memoria locale; per riusi serve il permesso degli aventi diritto.
